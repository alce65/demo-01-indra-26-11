# Demo 01

Ejemplo de repositorio en un curso de git. Este repositorio contiene un ejemplo de cómo se puede estructurar un proyecto y cómo se pueden utilizar las funcionalidades de Git para el control de versiones.

Los primeros comandos que veremos son:

- git init: Inicializa un nuevo repositorio de Git en el directorio actual.
- git add: Agrega archivos al área de preparación (staging area) para que estén listos para ser confirmados (committed).
- git commit: Crea un nuevo commit con los cambios que se han agregado al área de preparación.
