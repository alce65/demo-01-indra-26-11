# Demo 01

Ejemplo de repositorio en un curso de git. Este repositorio contiene un ejemplo de cómo se puede estructurar un proyecto y cómo se pueden utilizar las funcionalidades de Git para el control de versiones.

Los primeros comandos que veremos son:

- git init: Inicializa un nuevo repositorio de Git en el directorio actual.
- git add: Agrega archivos al área de preparación (staging area) para que estén listos para ser confirmados (committed).
- git commit: Crea un nuevo commit con los cambios que se han agregado al área de preparación.
- git status: Muestra el estado actual del repositorio, incluyendo los archivos modificados, los archivos en el área de preparación y los archivos no rastreados.
- git log: Muestra el historial de commits del repositorio, incluyendo los mensajes de commit, los autores y las fechas.

Hemos visto:
- Reescribir la historia: 
  - git commit --amend: Permite modificar el último commit, ya sea para cambiar el mensaje de commit o para agregar cambios adicionales.
  - git rebase: Permite reescribir la historia de commits, moviendo o combinando commits existentes en una nueva base.
  - git reset: Permite deshacer cambios en el área de preparación o en el historial de commits, eliminando commits o moviendo la rama a un estado anterior.
